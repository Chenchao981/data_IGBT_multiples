# FT数据清洗工具 - 快速入门指南

## 🚀 5分钟快速上手

### 步骤1：安装依赖 (首次使用)
```
双击 → install_dependencies.bat → 等待完成
```

### 步骤2：启动程序
```
双击 → startup_program.bat
```

### 步骤3：使用程序
1. **选择封装厂和处理类型**: 日月新 / 杰群 / 电基 / 集佳；DC / DVDS / RG / FT-ALL
2. **选择输入文件夹**: 包含Excel文件的文件夹
3. **选择输出文件夹**: 保存结果的文件夹
4. **点击开始清洗**: 等待处理完成；电基 FT-ALL 使用 `<产品主体>_NNN` 流水目录，集佳 FT-ALL 使用 `<首个lot_ID>_NNN` 流水目录
5. **散点图 / 箱体图**: 完成日月新DC、杰群DC或电基FT-ALL清洗后点击右侧“散点图 / 箱体图”；选择参数并点击“绘制图形”，浏览器按需生成可下载的白底静态 PNG

电基 dj8 已验证的 PowerTECH 文本文件即使外部文件名省略产品并带 `(1)` 等数字复制后缀，也可直接选择原目录清洗；程序会用文件内 `DataFileName`、测试程序名和 `Lot` 严格核对身份，不需要手工改名。

电基 PowerTECH 会从 `Item Name/Bias/Unit` 动态识别业务参数。测试程序在右侧增加的新参数会自动进入清洗、散点图和 PAT；`CONT*`、`SAME`、`DELAY` 等设备控制项不会进入结果。身份、单位或已有参数含义冲突时仍会停止并提示。

| 文件 | 用途 | 操作 |

## ⚠️ 常见问题

**Q: 双击startup_program.bat没反应？**
A: 先运行"install_dependencies.bat"安装依赖包

**Q: 提示找不到Python？**
A: 确保安装了Anaconda，或用Anaconda Prompt运行

**Q: 处理失败？**
A: 检查输入文件夹中是否有正确的Excel文件
