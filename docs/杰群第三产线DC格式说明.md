# 杰群第三产线 DC 数据格式说明

## 1. 识别结论

第三产线仍是杰群 DTA CSV，参数语义、单位、Bias、批次提取规则及标准输出均与
既有杰群格式1 DC一致。差异仅在目录结构和数据行宽度：

- GUI：杰群面板选择 `DC-3`。
- 目录：`data/DC1/<产品>/*.CSV`，不设 `DC/` 子目录。
- 文件：同批次可包含 `FADTA`、`FRDTA`、`FA1DTA`，全部作为测试记录纳入。
- Item 行：第17行；Serial 行：第34行。
- Item/Serial 宽度：常见25字段或2字段；完整数据另有13个文件因行末空逗号显示为26字段。
- 数据行：3～47字段；超出有效测试项的尾部字段均为空。
- Bin：保留源记录但不作为输出列，不按 PASS/FAIL 过滤，行为与既有杰群 DC一致。

## 2. 参数与单位

源文件包含 CONT、VTH、BVDSS、IDSS、ISGS、RDON、VFSDS、ABSDEL 和 SAME。
继续使用 `JIEQUN_DC_PARAMS` 与 `JIEQUN_DC_SKIP_MATCH_COUNTS`：只跳过第一个占位型
VTH，保留两列有效 IDSS，并排除 CONT/SAME。

标准输出参数为：

```text
VTH1(V), VTH2(V), VTH3(V),
BVDSS1(V), BVDSS2(V), IDSS-35(nA), IDSS-40(nA),
ISGS10(nA), IGSS10(nA), ISGS20(nA), IGSS20(nA),
ISGS22(nA), IGSS22(nA), RDON-40(mR),
VFSDS(V), ABSDEL1, ABSDEL2
```

单位换算继续执行：IDSS/ISGS/IGSS `A→nA ×1e9`，RDON `Ω→mR ×1000`。

## 3. 解析规则

既有 parser 曾按 `Serial,Bin` 行或首条数据推断列数。第三产线失败记录会因测试
提前终止而留下数量不等的尾随逗号，导致后续宽行触发 `ParserError`。

当前规则：

1. 流式扫描数据段，取得实际最宽字段数；不使用表头宽度。
2. pandas 使用实际数据宽度，只读取其中存在的目标参数列。
3. 删除所有目标 DC 参数均为空的记录，保留部分参数为空的提前终止记录。

完整100文件验证发现13个文件的 Item/Serial 行为26字段、实际数据最多25字段。
若用表头宽度强制指定 pandas 列数，会报 `expected 26 and found 25`；当前规则已规避。

## 4. 2026-07-02 样本验证

| 批次 | 源记录 | 清洗记录 | 全目标参数为空而删除 |
| --- | ---: | ---: | ---: |
| 1JSa198 | 75,619 | 75,597 | 22 |
| 1JSa3AA | 73,560 | 73,146 | 414 |
| 1JSa4AU | 72,209 | 71,857 | 352 |
| 合计 | 221,388 | 220,600 | 788 |

输出验证：

- 工作表：`DC_Data`。
- 列结构：`NUM + 批次 + 17个DC参数`。
- NUM：1～220,600，连续且唯一。
- 批次：无空值，批次数与源文件名一致。
- 代表值：VTH不换算；IDSS/ISGS/IGSS与源值×1e9一致；RDON与源值×1000一致。
- 可变宽源文件与固定25字段旧式布局抽样1,000行结果完全一致。

验证输出位于 `output/DC1-validation/`，属于本地生成数据，不应加入版本库或发布包。

## 5. 2026-07-14 56项平铺 DC 变体

新增样本仍应使用 GUI 的 `DC-3`，判断依据不是文件是否平铺，而是 `Item` 行只有
DC 参数、没有 `DVDS` 或 `LCR-RG`。该变体在一个 CSV 中连续导出两组28项测试，
因此共有56个测试项，数据行也可能宽于早期第三产线样本。

其中测试21、22、47、48均为 `RDON`，`Bias 1 Value` 都是20A，但测试21/22的
`Bias 2 Value`（VGS）不同。仅按 Bias 1 构造列名会得到重复的 `RDON20(mR)`；
旧去重逻辑因而只保留第一列。当前解析器按源顺序保留全部同名 RDON，输出为：

```text
RDON20-1(mR), RDON20-2(mR), RDON20-3(mR), RDON20-4(mR)
```

测试22对应 `RDON20-2(mR)`。代表样本验证结果为115,180行、34列；源文件申报
115,926条记录，其中746条记录的全部目标DC参数为空，按既有规则删除。代表首行
测试21/22由源值0.01048/0.01290 Ω正确换算为10.48/12.90 mR。
