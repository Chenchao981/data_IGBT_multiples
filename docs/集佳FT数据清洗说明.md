# 集佳 FT 数据清洗说明

## 支持范围

- 产品：`NCE15TD120BT`
- 来源：集佳 STS8203 CSV
- 编码：GB18030
- 输入文件名：`NCE15TD120BT_<C批次>_<测试批次>_DC_<YYMMDDhhmmss>.csv`
- 已验证批次提取：`(?<=_)(C\d{6}\.\d{2})(?=_)`

当前只注册真实样本验证过的 123 列字段顺序和单位。产品、字段、顺序、单位、文件名或
测试批次元数据不一致时停止处理，不按相似格式猜测。

## 输出合同

- 工作表：`DC_Data`
- 列顺序：`NUM + lot_ID + 117个测试参数`
- `lot_ID`：文件名中的 `Cxxxxxx.xx`
- 参数名称：有单位时输出为 `参数名(单位)`，无单位时保留参数原名
- 不保留：`SITE_NUM`、`PART_ID`、`PASSFG`、`SOFT_BIN`、`T_TIME`、`TEST_NUM`
- 不换算单位：输出数值与源文件 `Unit` 行一致
- PASS 和 FAIL 记录全部保留；FAIL 后未执行的测试参数为空值
- 多文件按文件名排序后合并，`NUM` 从 1 连续编号
- 每次运行创建 `<首个lot_ID>_NNN` 流水目录，避免覆盖历史结果

## GUI 操作

1. 左侧选择“集佳 (Jijia)”。
2. 选择 `FT-ALL`。
3. 输入目录选择包含集佳 CSV 的文件夹。
4. 输出目录选择清洗结果保存位置。
5. 点击“开始清洗”。

命令行也可运行：

```powershell
python -m factories.jijia.dc_cleaner <输入目录> <输出目录>
```
