# 杰群 RG 已清洗输出目录处理完成报告

- 完成日期：2026-08-25
- 发布版本：v2.14.2

## 问题

用户在杰群 `RG` 按钮中选择了：

`F:\data\CP和FT源数据\FT数据\杰群data\DC-AI统一验证\CJSx185_001`

该目录不是 RG 原始目录，而是统一 CSV 清洗后的输出目录。旧逻辑继续寻找其下级 `/RG`，因此报 `FileNotFoundError`。

## 事实核对

- 目录内有 `CJSx185_001_DC.xlsx`、`CJSx185_001_DVDS.xlsx`、`CJSx185_001_RG.xlsx`。
- RG 工作簿包含合法 `RG_Data` 工作表。
- RG 结果为 49,142 行、3 列：`NUM + 批次 + RG(R)`。
- 对应原始统一 CSV 位于杰群 `RAW` 目录；需要重新清洗时应使用 `DC-AI`。

## 修复

- DVDS/RG 清洗器在寻找原始子目录前，先检查当前目录是否已经包含对应的合法结果工作簿。
- 只有一个合法结果时，返回该文件并记录“跳过重复清洗”，不复制、不覆盖、不重新计算。
- 多个同类型结果时拒绝猜测，要求用户选择明确的单批次目录。
- 专用清洗真正生成新结果时记录明确的 `last_output_file`，GUI 完成结果可追溯到具体工作簿。

## 验证

- 用户报错的真实目录已验证返回成功，并定位到现有 `CJSx185_001_RG.xlsx`。
- 新增 RG、DVDS 现成结果与多结果歧义测试。
