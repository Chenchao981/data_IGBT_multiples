# 杰群专用 DVDS/RG 入口恢复完成报告

- 完成日期：2026-08-25
- 发布版本：v2.14.1

## 结论

杰群清洗区最终保留 `DC-AI / DVDS / RG` 三个按钮，只隐藏 `DC-1 / DC-统一CSV / DC-3` 三个手工 DC 格式入口。

## 原因

产品根目录可以由 DC-AI 识别 DC 格式并自动配对同级 DVDS/RG；但纯 DVDS 或纯 RG 目录不含 DC 参数，按严格识别规则必须拒绝作为 DC 输入。将专用按钮全部移除会让这类合法业务目录失去入口。

真实目录 `NCEAP065NHD40AG(M)-1J00 JQ PAT/DVDS` 已复现该边界：交给 DC-AI 会明确报告“未找到可用于 DC 判断的 DTA CSV”，而专用 `JiequnDVDSCleaner` 能按既有契约正常处理。

专用入口真实验收读取 2 个文件，其中 81,286 行和 127,010 行，共输出 208,296 行、
3 列（`NUM + 批次 + DVDS(mV)`）到 `DVDS_Data`，清洗成功。

## 最终操作规则

- 有产品根目录或 DC/统一CSV/第三产线数据：使用 `DC-AI`。
- 只有纯 DVDS 目录：使用 `DVDS`。
- 只有纯 RG 目录：使用 `RG`。
- DC-AI 对分目录产品根目录的一键 DC/DVDS/RG 能力继续保留。

## 稳定性

- 没有修改 DVDS/RG 解析、单位换算、参数命名和输出格式。
- 专用按钮直接调用原有成熟清洗器。
- DC-AI 仍拒绝把纯 DVDS/RG 猜成 DC 类型。
- 发布前执行真实 DVDS 目录、自动化测试、打包内容审计和最终 GUI 验收。
