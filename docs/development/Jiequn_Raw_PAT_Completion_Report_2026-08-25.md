# 杰群原始数据 PAT 直算完成报告

- 完成日期：2026-08-25
- 发布版本：v2.13.0
- 适用范围：杰群（Jiequn）PAT 参数分析

## 1. 交付结论

杰群 PAT 已改为从用户预览并选定的原始 DTA CSV 目录直接计算，固定流程为：

`逐文件提取参数 → 分参数临时落盘 → 直接计算 PAT → 输出 PAT_NNN/PAT_NNN.xlsx`

不再要求用户先运行清洗、再从大型清洗 Excel 读取参数。杰群现有 DC、DVDS、RG 清洗入口保持不变；日月新、电基等其他封装厂的 PAT 入口保持其既有、已验证的数据契约，本里程碑未擅自改写。

## 2. 已完成内容

### 2.1 原始文件计算链路

- 支持杰群 DC-1、DC-统一 CSV、DC-3 的格式识别和逐文件解析。
- 对经典 DC 目录自动组合相邻的 DVDS、RG 数据目录，避免同一参数重复统计。
- 对统一 CSV 一次解析目标 DC、DVDS、RG 参数。
- 参数数值按 `float64` 分流写入临时文件；完成提取后每次只载入一个参数计算全局统计量。
- 沿用现有单位换算规则和 PAT 公式：`Sigma=(Q3-Q1)/1.35`，`LCL/UCL=median±6×Sigma`。
- 成功或异常退出均清理临时参数文件。
- 拒绝混合产品、同组参数结构漂移和跨数据组重复参数，避免静默生成错误结果。

### 2.2 GUI 操作

- 杰群面板选择 `PAT` 后，输入项显示为 `PAT 原始文件目录`。
- 浏览按钮显示为 `预览文件目录...`，打开 Windows 文件夹选择器。
- 操作按钮显示为 `计算 PAT`。
- 输出仍采用防覆盖流水目录 `PAT_001/PAT_001.xlsx`、`PAT_002/PAT_002.xlsx`。

### 2.3 发布包

- 版本升级为 v2.13.0。
- 已重建 `packaging/release/ft_data_cleaner.pyz` 并同步使用说明。
- 发布包不包含源数据、测试数据、Excel 结果、日志、Markdown 文档或缓存文件。

## 4. 做得较好的地方

- 将清洗与 PAT 解耦，用户只需选择原始目录并点击一次计算。
- 没有把 680 多万行拼成一个巨型 DataFrame，也没有生成中间清洗 Excel。
- 统计量基于全部有效数值计算，不使用分批统计量近似四分位数。
- 对格式、产品和参数边界采用明确校验，发现歧义即停止。
- 源码版、打包版和历史全量基准形成三方核对。

## 5. 已知限制与风险

- 为保持精确四分位数，临时磁盘占用约等于所有有效参数值数量乘以 8 字节；本次样本峰值预计接近 1.2 GiB，运行前应保证系统临时目录有足够空间。
- 计算单个参数的精确四分位数时，该参数的全部数值会进入内存；本次最大参数约 681 万个值，约 55 MiB，明显低于整表加载，但仍不是常数内存。
- 当前后台任务沿用既有 Worker，尚无“中途取消”按钮。
- 真实 520 文件验收覆盖统一 CSV；经典 DC/DVDS/RG 组合目前由自动化样本验证，后续取得相应真实批次时应再做一次生产数据核对。
- 为确认每个文件的实际数据宽度，解析过程仍会对文件执行结构扫描和数据读取；本次真实批次运行约 100 秒，GUI 期间会持续输出进度，并非卡死。

## 6. 后续建议

2. 可在后续版本增加临时磁盘空间预检和任务取消能力。
