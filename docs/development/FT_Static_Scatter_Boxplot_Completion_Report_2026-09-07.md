# FT 静态散点图与箱体图完成报告

日期：2026-09-07
版本：v2.21.0

## 1. 结论

FT 参数图表已改为静态 PNG，并接入源码 GUI 与本机发布包。实现保留 FT 自身数据契约，没有复制 CP 的晶圆分组：

- `lot_ID`：完整 FT 批次身份，也是新增箱体图的唯一分组键；不截断、不拼造 `Wafer_ID`。
- `NUM`：只用于批次内样本的稳定展示顺序，不作为时间轴或统计子组。
- `Source_ID`：只用于来源追溯以及规格、单位和测试条件绑定，不拆分箱体。
- Cleaner、原始测量值、有效值、复测记录、Bin、良率、PAT 和 Cpk 逻辑均未修改。

仓库此前只有 FT Plotly 散点图，没有可回归的 FT 箱体图统计实现。新增箱体图因此明确采用“每个完整 `lot_ID` 一个箱体、全部有限值、NumPy linear 分位数、1.5 IQR 围栏内实际最小/最大值为箱须”的图表口径；它不是旧 FT 统计结果，也不改变 PAT 等业务统计。

## 2. 已完成内容

1. 新增 FT 专用静态渲染层：每参数一张白底 PNG，散点全量绘制有限值、不抽样；箱体不叠加原始点和离群点标记。
2. 每个批次等宽排列并稳定分色；缺测位置不左移，空批次保留，长批次号保持完整。
3. 默认按每个批次分别计算主体范围，再合并为聚焦纵轴；散点图和箱体图各有独立完整纵轴开关。
4. 图下显示范围外有限值数量；规格线按 `Source_ID` 绑定，规格在视窗外时给出汇总提示。
5. 对有效测量来源执行严格契约校验：缺规格、规格 lot 不匹配、Source 跨 lot、空或不兼容单位/测试条件、非法或无限规格值均停止该参数绘图。
6. 只有已审核 PowerTECH `DELTA BV`、`DELTA VTH` 允许不同 `Value=#N` 引用号按同一语义比较；其他参数的测试条件必须精确一致。
7. 页面首次只读清单与筛选，点击“绘制图形”后才加载数据和生成图；PNG 缓存键覆盖数据文件/规格文件版本、参数、图型、聚焦状态和样式版本。
8. GUI 入口统一为“散点图 / 箱体图”；外部程序占用 8502 时自动选择后续空闲端口，只复用当前 GUI 自己启动且仍存活的服务。
9. 发布说明、依赖、GUI 版本、源码前端和发布包同步更新到 v2.21.0。

## 3. 验证结果

### 3.1 自动回归

- 最终全套单元/集成测试：153 项全部通过，用时 10.934 秒。
- 专项覆盖：1/2/3 批次、43 色扩展、单值、常数、IQR=0、空批次、缺测/非数值/无穷值、聚焦/完整视窗、来源规格差异、规格非连续区段、条件/单位冲突、前导零身份、页面懒加载、PNG 下载控件和端口隔离。
- 2,000 行 A/B 来源交替的规格区段：规格线没有跨错来源；批量绘制后约 0.53 秒、3 个 collections、4 个规格文字，避免逐段创建数千个图形对象。
- 合成 1,000,000 行：批次布局约 0.882 秒，单参数规格契约校验约 0.092 秒。

### 3.3 真实杰群 8 批次大样本

全目录当前共有 100 个 DTA/DC CSV、43 个 `lot_ID`。为覆盖需求中的 8 批次场景，固定选取 `1JSa198`、`1JSa299`、`1JSa3AA`、`1JSa4AU`、`1JSC159`、`1JSC260`、`1JSC358`、`1JSd129`；该集合只用于验收，不是新增业务筛选规则。

- 输入：17 个真实源文件，合计 147,566,754 bytes。
- 合并：589,854 行、18 个参数、17 个 `Source_ID`、306 条规格。
- 输出检查：18 张散点图和 18 张箱体图全部在内存成功生成；所有参数的箱体数均为 8。
- 数据一致性：每个参数的散点与箱体有效值数相同；严格规格、单位、条件校验失败为 0。
- 耗时：解析 3.733 秒，合并/布局 0.994 秒，渲染 44.371 秒，端到端 49.121 秒。
- 图片体积：散点合计 8,126,636 bytes，箱体合计 1,622,228 bytes，总计 9,748,864 bytes。
- 内存：RSS 起始 83.59 MiB，峰值 473.59 MiB，增量 390.00 MiB，结束 439.24 MiB。
- I/O：17 个源文件的 size/mtime 前后完全一致；图表只使用 `BytesIO`，没有结果文件或持久临时图形文件。

旧 Plotly 页面会对点进行采样，而新散点图绘制全部有限测量值，因此生成耗时和体积不能作为等量数据的直接前后性能对比。新实现的主要收益是静态页面传输、可下载图片、清晰纵轴和确定的数据契约，而不是宣称全量绘制一定比采样更快。

## 6. 运行方式

1. 运行 `packaging/release/startup_program.bat`。
2. 完成日月新 DC、杰群 DC-AI 或电基 FT-ALL 清洗。
3. 点击“散点图 / 箱体图”。
4. 选择参数和图表类型，点击“绘制图形”；按需切换对应图型的完整纵轴，并逐参数下载 PNG。
