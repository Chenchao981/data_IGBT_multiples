# FT 数据清洗工具用户快速上手说明

本文档面向第一次使用本工具的用户，按步骤操作即可完成数据清洗。

## 1. 工具能做什么

FT 数据清洗工具用于把封装厂提供的测试数据整理成统一格式的 Excel 输出文件。

当前支持：

| 封装厂 | 原始文件类型 | 支持处理 |
| --- | --- | --- |
| 日月新 ASE | `.xlsx` | DC、DVDS、RG、PAT、SYL&SBL |
| 杰群 Jiequn | `.csv` | DC、DC-3、DVDS、RG、统一 CSV、PAT、SYL&SBL |
| 电基 Dianji | PowerTECH 伪 `.xls`、STS8203 `.csv` / 清洗后 `.xlsx` | FT-ALL、PAT、SYL&SBL |

常见输出结果：

| 处理类型 | 输出内容 |
| --- | --- |
| DC | DC 参数清洗结果 |
| DVDS | DVDS 参数清洗结果 |
| RG | RG 参数清洗结果 |
| 统一 CSV | 一次性输出 DC、DVDS、RG 结果 |
| PAT | 基于已清洗结果生成统计汇总表 |
| SYL&SBL | 基于良率报表生成良率、Fail Bin 和 3Sigma/4Sigma 分析 |

## 2. 使用前准备

请先确认电脑中已经准备好：

1. 原始测试数据文件夹。
2. 一个用于保存结果的输出文件夹。
3. Python 环境和项目依赖。

如果是第一次运行，在项目根目录执行：

```powershell
pip install -r requirements.txt
```

项目根目录指包含 `requirements.txt`、`gui`、`factories` 等文件夹的位置。

## 3. 启动软件

推荐方式：双击运行：

```text
gui/start_gui.bat
```

也可以在项目根目录打开命令行，执行：

```powershell
python -m gui.main_window
```

启动成功后，会看到左侧是封装厂列表，右侧是对应封装厂的数据处理面板。

## 4. 基本操作流程

每次清洗都按下面 5 步操作：

1. 在左侧选择封装厂。
2. 在右侧选择处理类型，例如 `DC`、`DVDS`、`RG`。
3. 选择“数据文件夹”，也就是原始数据所在目录。
4. 选择“输出文件夹”，也就是清洗结果保存目录。
5. 点击“开始清洗”，等待处理完成提示。

处理过程中，下方“处理状态”区域会显示日志。看到完成弹窗后，再到输出文件夹查看生成的 Excel 文件。

## 5. 日月新 ASE 数据怎么选

日月新数据通常是 `.xlsx` 文件。

建议按处理类型选择对应目录：

| 要处理 | 数据文件夹建议选择 |
| --- | --- |
| DC | 包含 DC 原始 `.xlsx` 文件的目录 |
| DVDS | 包含 DVDS 原始 `.xlsx` 文件的目录 |
| RG | 包含 RG 原始 `.xlsx` 文件的目录 |

示例目录结构：

```text
ASEData/
  DC/
    xxx.xlsx
  DVDS/
    xxx.xlsx
  RG/
    xxx.xlsx
```

如果数据已经分好了 `DC`、`DVDS`、`RG` 子目录，处理哪一种就选择对应子目录。

## 6. 杰群 Jiequn 数据怎么选

杰群支持两类常见输入。

### 6.1 分目录格式

如果原始数据已经按 `DC`、`DVDS`、`RG` 分目录存放：

```text
data/杰群/
  某个批次目录/
    DC/
      xxxDTA.CSV
    DVDS/
      xxx_DVDSDTA.CSV
    RG/
      xxx_RGDTA.CSV
```

操作方式：

| 要处理 | 按钮 | 数据文件夹建议选择 |
| --- | --- | --- |
| DC | `DC` | 选择 `data/杰群` 或包含 `DC` 子目录的上级目录 |
| DVDS | `DVDS` | 选择 `data/杰群` 或包含 `DVDS` 子目录的上级目录 |
| RG | `RG` | 选择 `data/杰群` 或包含 `RG` 子目录的上级目录 |

程序会自动向下查找对应的 `DC`、`DVDS`、`RG` 子目录。

杰群第三产线 DC 数据如果直接放在 `DC1/产品目录/*.CSV`，选择 `DC-3` 按钮后，
“原始数据文件夹”可直接选择 `DC1` 根目录或具体产品目录；程序会递归查找 DTA CSV。

### 6.2 统一 CSV 格式

如果一个 CSV 文件里同时包含 DC、DVDS、RG 参数，选择 `统一CSV`。

建议数据文件夹选择：

```text
data/杰群2/RAW
```

输出文件夹可选择：

```text
output/杰群2
```

处理完成后，会分别生成 DC、DVDS、RG 的清洗结果。

## 7. 电基 Dianji 数据怎么选

在电基面板选择 `FT-ALL`，数据文件夹可以包含一种已支持格式：

- PowerTECH 伪 `.xls` 文本；
- STS8203 `.csv` 文件。

同一次清洗只放同一产品、同一已验证格式族的数据。程序会核对文件名、批次和文件内
元数据，成功后在输出根目录创建 `<产品主体>_001`、`_002` 等流水目录。清洗 Excel
与 FT 散点数据包都放在该流水目录内，不会覆盖以前的结果。

## 8. PAT 统计怎么用

`PAT` 不是直接处理原始数据，而是对已经清洗好的参数输出文件做统计。

使用步骤：

1. 先完成日月新/杰群 DC、DVDS、RG 清洗，或电基 FT-ALL 清洗。
2. 在对应的日月新、杰群或电基面板中选择 `PAT`。
3. 点击“选择文件”，选择一个或多个已清洗 Excel 文件：

```text
1JSa198_001.xlsx
或同时选择 DC.xlsx、DVDS.xlsx、RG.xlsx
```

   如果单个文件因超过 Excel 行数限制被拆成 `DC_Data_1`、`DC_Data_2`、
   `DC_Data_3`，PAT 会逐个 Sheet 读取，并按参数合并全部数据后计算。
   电基选择含 `RAW` 工作表的 `<产品> DJ PAT.xlsx`；若存在 `RAW_1/RAW_2`，
   同样会合并完整数据。
4. “输出文件夹”选择 PAT 报表保存目录。
5. 点击“生成 PAT”。

完成后会生成 `PAT.xlsx` 或类似命名的统计文件。

日月新、杰群与电基 PAT 使用相同计算规则：`Sigma = (Q3 - Q1) / 1.35`，
`LCL/UCL = 中位数 ± 6 × Sigma`。

PAT 使用 Calamine 优先读取；多个编号 Sheet 不会分别计算后平均，而是先合并
同名参数的全部原始值，再计算整体四分位数和控制限。

## 9. SYL&SBL 统计怎么用

1. 在日月新、杰群或电基面板中选择 `SYL&SBL`。
2. 点击“选择文件”，选择一份封装厂良率报表 `.xls` 或 `.xlsx` 文件。
3. “输出文件夹”选择报表保存目录。
4. 确认输入框显示的是目标良率文件完整路径，然后点击“生成 SYL&SBL”。

SYL&SBL 不支持选择文件夹，也不会自动推断“最新”良率文件，避免误处理其他批次。

报表按 `良率 = PASS / Test Input`、`Fail Bin rate = Bin fail count / Test Input`
计算，并生成 3Sigma、4Sigma 的 SYL/SBL 控制限。

## 10. 如何确认处理完成

以下情况表示任务已经结束：

1. 软件弹出“完成”提示。
2. “开始清洗”按钮从“清洗中...”恢复为可点击状态。
3. 输出文件夹里出现新的 Excel 文件。

如果日志停在“单位换算完成”，不一定代表卡住。对于几十万行以上的大数据，后面还需要写入 Excel 文件，这一步可能需要较长时间。

## 11. 输出文件在哪里

输出文件会保存在你选择的“输出文件夹”中。

文件名通常包含：

| 文件名部分 | 含义 |
| --- | --- |
| 批次或 `mixed` | 数据批次信息；多个批次混合时通常显示 `mixed` |
| `DC`、`DVDS`、`RG`、`PAT` | 处理类型 |
| 时间戳 | 生成时间，避免覆盖旧文件 |

示例：

```text
mixed_DC_20260604_110412.xlsx
```

## 12. 常见问题

### 12.1 点击开始后提示找不到目录

检查“数据文件夹”是否选对。

日月新通常选择包含 `.xlsx` 文件的目录。杰群分目录格式可以选择包含 `DC`、`DVDS`、`RG` 子目录的上级目录。

### 12.2 日志显示完成了，但界面还在清洗中

请继续等待一会儿。日志中的“合并完成”“单位换算完成”只是中间步骤，最终还要保存 Excel。

如果数据量很大，比如接近百万行，保存 Excel 可能明显变慢。

### 12.3 输出文件打不开

常见原因：

1. 文件还没写完就打开了。
2. 同名文件正在被 Excel 占用。
3. 输出目录没有写入权限。

建议关闭正在打开的结果文件，重新运行一次。

### 12.4 没有生成结果文件

请先看“处理状态”里的最后几行日志。常见原因包括：

1. 原始目录选错。
2. 原始文件格式不符合当前处理类型。
3. 原始文件中没有可识别的目标参数。
4. 输出目录无权限或磁盘空间不足。

### 12.5 文件很多或数据很大时要注意什么

建议：

1. 先只放少量文件试跑，确认输出格式正确。
2. 正式处理时不要同时打开输出目录里的同名 Excel 文件。
3. 大数据保存 Excel 较慢，请等待完成弹窗。
4. 输出文件生成后再打开查看。

## 13. 推荐的新手操作顺序

第一次使用建议按这个顺序：

1. 准备一小批测试数据。
2. 启动 `gui/start_gui.bat`。
3. 选择对应封装厂。
4. 选择一个处理类型，例如 `DC`。
5. 选择原始数据文件夹和输出文件夹。
6. 点击“开始清洗”。
7. 确认输出文件能正常打开。
8. 再处理完整批次数据。

## 14. 给现场用户的简短版流程

可以直接记住这一句话：

选择封装厂，选择 DC/DVDS/RG，选择原始数据目录，选择输出目录，点击开始清洗，等完成弹窗，再去输出目录拿 Excel。
